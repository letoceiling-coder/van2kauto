# Витрина, заявки и Telegram-бот

Админка: https://vanauto-api.neeklo.ru/che168 → разделы «Витрина», «Заявки», «Бот», «Настройки».

## Подключить бота (один раз)
1. @BotFather → /newbot → скопировать токен.
2. Настройки → «Токен бота» → вставить → Сохранить.
3. Создать группу менеджеров, добавить туда бота, написать в группе `/id` — бот пришлёт chat_id
   (сначала нажмите «Установить вебхук», иначе бот не ответит).
4. Настройки → «Чаты для заявок» → вставить chat_id (можно несколько через запятую) → Сохранить.
5. «Проверить бота и чаты» — в группу придёт тестовое сообщение.

## Как работает
- Заявка с сайта: POST /api/v1/leads → таблица leads → сообщение в каждый чат менеджеров с кнопками
  «Взял в работу / Спам / Закрыть». Статус и менеджер видны в админке. Не ушла — повтор каждые 5 минут.
- Бот: /start → приветствие + кнопка «Отправить номер» → заявка. Ссылка с карточки: t.me/<бот>?start=car_<slug>.
  Любая метка (?start=insta) попадает в UTM заявки и в подписчика. Тексты — в настройках.
- Рассылки: «Бот» → текст/фото/кнопка → «Тест менеджерам» → «Отправить всем». В канал бот не пишет.
- Витрина: карточки вручную или «В витрину» из объявлений (фильтр «Проходные», мощность).
  В карточке — «Совпадения в фиде» и «Подставить характеристики». Без цены «от» не публикуется.
- Сайт: статический, данные витрины вшиваются при сборке. Правило пересборки — в настройках
  (вручную / через N минут после изменений / раз в сутки). Сборка: /opt/van2kauto/deploy/rebuild.sh.
  Пока витрина пустая — на сайте демо-каталог.
