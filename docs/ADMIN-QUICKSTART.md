# Админка ВАН23АВТО — краткая инструкция

**Вход:** https://vanauto-api.neeklo.ru/che168/login (логин и пароль — в файле `ДОСТУПЫ-АДМИНКА.txt`).

## Каждый день (5 минут)
1. **Заявки** приходят в Telegram-группу менеджеров. Нажмите «✅ Взял в работу».
2. **Чат с сайта.** Вопрос из блока «Спросите — ответит живой человек» приходит в группу. **Ответьте на это сообщение реплаем** (свайп влево / «Ответить») — клиент увидит ответ на сайте через несколько секунд. Если клиент пришёл из бота, ответ придёт ему и в бота. Ответить можно и из админки: «Заявки» → заявка → «Ответить».
3. **«Заявки»** в админке — полная история, заметки, статусы.

## Парсер che168
- Работает сам: **новые объявления — каждый день в 05:00 (по UTC)**, **полный обход с отметкой проданных — по воскресеньям**. Включается и выключается в «Настройки → Парсер che168».
- Запустить вручную: «Парсер» → «Искать новые» (быстро) или «Запуск парсера» (полный обход).
- **Капча:** если che168 попросит проверку, в Telegram придёт сообщение. Откройте «Captcha» в меню, пройдите проверку, затем «Парсер» → «Продолжить». Токен проверки живёт около 30 дней.
- Мощность у объявлений определяется сама. Фильтры «Мощность до» и кнопка **«Проходные»** — в «Объявлениях».

## Витрина и топ-10
- **«Витрина» → «Топ-10 из фида»** собирает самые востребованные «проходные» модели по числу предложений на рынке:
  - отбирает бензин, дизель и обычные гибриды до 160 л.с., возрастом 3–5 лет;
  - для каждой модели берёт самое доступное объявление с хорошими фото;
  - фото скачивает к нам, цену «от» считает по формуле;
  - уже добавленные модели не дублирует.
  Галочка «сразу на сайт» — публикация без проверки.
- Цену любой карточки можно поправить вручную или кнопкой «По формуле».
- Карточку можно скопировать, снять с публикации, поставить в хиты и поменять порядок.
- **Топ-10 на главной** — это опубликованные карточки с отметкой «хит», в порядке из «Витрины».

## Цена «от» по формуле
«Настройки → Цена «от» по формуле»:

(цена у продавца + экспорт + порт, $) × курс × коэффициент + фикс. добавка, округление вниз.

- Курс $ обновляется по ЦБ каждый день.
- Сейчас стоят коэффициент **1,35** и добавка **250 000 ₽**. Это стартовые значения: **сверьте с 2–3 реальными сделками и поправьте**.
- После изменения формулы нажмите «По формуле» в нужных карточках, либо удалите их и соберите топ заново.

## Сайт
- После любых правок витрины сайт пересобирается сам через 5 минут. Срочно — «Пересобрать сайт сейчас».
- Правило пересборки меняется в «Настройки → Сайт и пересборка».

## Доступы
На сервере, в `/var/www/vanauto-api.neeklo.ru`:
```
runuser -u www-data -- php artisan admin:user manager@example.ru --name="Руслан"   # новый менеджер
runuser -u www-data -- php artisan admin:user admin@vanauto.neeklo.ru --reset        # новый пароль
```

## Если что-то не работает
| Симптом | Что сделать |
|---|---|
| Заявки не приходят в Telegram | «Настройки» → «Проверить бота и чаты». В «Заявках» видно ⚠️ и причину; повтор идёт каждые 5 минут. |
| Ответ в Telegram не дошёл до клиента | Отвечайте именно **реплаем** на сообщение заявки или клиента, а не обычным сообщением. |
| Парсер «needs_captcha» | Пройдите Captcha → «Продолжить». |
| Сайт не обновился | «Настройки» → «Сборки сайта»: статус и текст ошибки последней сборки. |
