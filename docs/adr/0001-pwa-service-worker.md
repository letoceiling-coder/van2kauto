# ADR 0001 — PWA и сервис-воркер без библиотек

Дата: 2026-11-23. Статус: принято.

**Контекст.** Сайт статический (Next.js export). На телефоне нужно ощущение приложения: установка на экран, быстрые повторные заходы, работа при плохой сети.

**Решение.**
- `app/manifest.ts` (standalone, иконки 192/512/maskable), `appleWebApp` в metadata.
- Сервис-воркер `public/sw.js`, руками, без зависимостей:
  - статика с хэшем, `/media`, `/brand` — cache-first;
  - HTML — network-first с запасной страницей `/offline/`;
  - чужие домены (API `vanauto-api`, админка, Метрика) и любые не-GET не кешируются;
  - кеш по `NEXT_PUBLIC_BUILD_ID` (ставит `deploy/rebuild.sh`), старые удаляются при активации.
- Выключатель: собрать с `NEXT_PUBLIC_SW=off` — воркер снимется у всех при следующем заходе.

**Последствия.** Повторные заходы мгновенные, офлайн открываются ранее просмотренные страницы. Риск устаревшего HTML снят стратегией network-first.
