# ВАН23АВТО — как устроена система

Состояние на 23.11.2026. Короткая инструкция для работы — [ADMIN-QUICKSTART.md](ADMIN-QUICKSTART.md).

## 1. Из чего состоит

| Часть | Адрес | Что делает |
|---|---|---|
| **Сайт** | https://vanauto.neeklo.ru | Витрина для клиентов: каталог, карточки авто, квиз, форма заявки. Статический (Next.js), грузится мгновенно. |
| **Админка** | https://vanauto-api.neeklo.ru/che168 | Витрина, заявки, бот, настройки, парсер che168, аукционы. Вход по логину и паролю. |
| **API** | https://vanauto-api.neeklo.ru/api/v1 | Связка: отдаёт сайту витрину, принимает заявки, отдаёт объявления фида. Документация: `/api/docs`. |
| **Парсер che168** | внутри админки | Собирает объявления с che168 (Китай) в базу — это «фид», сырьё для подбора. Клиенты его не видят. |
| **Telegram-бот** | подключается в «Настройках» | Присылает заявки менеджерам, принимает заявки от клиентов, делает рассылки подписчикам. |

```
 che168 ──парсер──► Фид объявлений (тысячи, сырьё)
                        │  «В витрину» / «Подставить характеристики»
                        ▼
                 Витрина (ваши карточки, цена «от», свои фото) ──API──► Сайт (пересборка по правилу)
                                                                          │
 Клиент ──форма на сайте──► API /leads ──► Заявки в админке ──► Telegram менеджерам [Взял / Спам / Закрыть]
 Клиент ──бот (/start, номер, сообщение)──────────────┘
 Админка ──рассылка──► подписчики бота
```

## 2. Как это работает

**Каталог на сайте = витрина из админки.** Сайт показывает только опубликованные карточки витрины. Пока ни одной нет — показывается демо-каталог.
- Карточка — это *модель-предложение* («Mazda CX-5 2023, от 2,9 млн ₽»), а не конкретное объявление. Объявление на che168 продалось — карточка остаётся.
- Карточку можно создать вручную или кнопкой «В витрину» из объявления фида: марка, модель, комплектация, мощность, привод, КПП и фото подставятся сами.
- На сайте только цена «от» и ваши фото (скачиваются на наш сервер). Ссылок на che168 и цен донора в долларах клиент не видит.
- Без цены «от» карточку опубликовать нельзя.
- «Проходной по утильсбору» считается сам: мощность до 160 л.с. и возраст 3–5 лет (правило меняется в «Настройках»), можно задать вручную.

**Пересборка сайта.** Сайт статический, поэтому после правок витрины его нужно пересобрать. Делается само по правилу из «Настроек»:
- *Автоматически после изменений* (сейчас включено): через 5 минут после последней правки. Пачка правок — одна сборка.
- *Раз в сутки* — в заданный час, если были изменения.
- *Только вручную* — кнопкой «Пересобрать сайт сейчас».

Сборка идёт на сервере около 10–15 секунд. Если API недоступен, сайт собирается с прошлыми данными, а не с пустым каталогом.

**Заявки.** Форма на сайте (карточка авто, квиз, контакты, «Подобрать авто») уходит в API.
- Заявка сразу сохраняется в «Заявках» и приходит в Telegram менеджерам. В ней машина, страница, рекламные метки (UTM) и ответы квиза.
- Кнопки в Telegram: «Взял в работу» → «Закрыть» или «Спам». Статус и имя менеджера видны в админке.
- Если Telegram не ответил (или бот не подключён) — заявка не теряется: повторная отправка каждые 5 минут.
- Защита: обязательное согласие на обработку ПДн, ловушка для ботов, не больше 5 заявок в минуту с одного адреса, приём только с сайта.

**Бот.**
- `/start` → приветствие и кнопка «Отправить номер» → заявка.
- Ссылка с конкретной машины: `t.me/<бот>?start=car_<slug>` — бот сразу называет машину.
- Любая метка, например `?start=insta`, попадает в заявку как источник.
- Обычное сообщение клиента тоже становится заявкой.
- Все тексты меняются в «Настройках». В канал бот ничего не публикует.

**Рассылки.** «Бот» → текст, фото и кнопка → «Тест менеджерам» → «Отправить всем». Уходят подписчикам бота по ~20 в секунду. Тех, кто заблокировал бота, система отмечает сама.

## 3. Краткая инструкция

**Вход:** https://vanauto-api.neeklo.ru/che168/login. Логин и пароль — в файле `ДОСТУПЫ-АДМИНКА.txt` (не в git).

**Подключить бота (один раз):**
1. В Telegram @BotFather → `/newbot` → скопировать токен.
2. Админка → «Настройки» → «Токен бота» → вставить → «Сохранить».
3. «Установить вебхук».
4. Создать группу менеджеров, добавить туда бота, написать в группе `/id` — бот пришлёт номер чата.
5. «Настройки» → «Чаты для заявок» → вставить номер → «Сохранить» → «Проверить бота и чаты». В группу придёт тестовое сообщение.

**Добавить машину на сайт:**
- *Из фида:* «Объявления» → кнопка «Проходные» (или свои фильтры: марка, год, мощность) → отметить галочками → «В витрину выбранные».
- *Вручную:* «Витрина» → «+ Новая карточка».
- Дальше в карточке: проверить поля, вписать **цену «от»**, при желании загрузить свои фото и выбрать обложку → «Опубликовать на сайте» → «Сохранить».
- Через ~5 минут карточка на сайте. Срочно — «Пересобрать сайт сейчас».
- Справа в карточке «Совпадения в фиде»: сколько похожих объявлений и их цены. «Подставить характеристики» берёт данные из выбранного объявления (цену и фото не трогает).
- Похожая модель в другой комплектации — «Создать копию», поправить комплектацию и цену.

**Порядок и хиты:** «Витрина» → номер порядка (меньше — выше) → «Сохранить порядок». «В хиты» — карточка попадёт в блок «Хиты» на главной.

**Заявки:** приходят в Telegram. В админке «Заявки» — история, фильтры, заметки, смена статуса.

**Добавить менеджера / сменить пароль** (на сервере):
```
cd /var/www/vanauto-api.neeklo.ru
runuser -u www-data -- php artisan admin:user manager@example.ru --name="Руслан"
runuser -u www-data -- php artisan admin:user admin@vanauto.neeklo.ru --reset
runuser -u www-data -- php artisan admin:user --list
```

## 4. Сервер и выкладка

- Сервер: `31.192.111.33` (общий, на нём и другие сайты).
- API и админка: `/var/www/vanauto-api.neeklo.ru` (Laravel 13, PostgreSQL `vanauto_api`).
- Сайт: собранная статика в `/var/www/vanauto.neeklo.ru`, исходники для пересборки в `/opt/van2kauto`.
- Планировщик: одна строка в cron root (`schedule:run` раз в минуту от `www-data`) — пересборка по правилу, рассылки, повтор заявок.
- Весь код в одном репозитории GitHub `letoceiling-coder/van2kauto` (ветка `main`): сайт — в корне, API и админка — в папке `api/`.
- Выложить сайт после правок кода: `deploy/deploy-source.sh`, затем «Пересобрать сайт сейчас» в админке.
- Выложить API: `deploy/deploy-api.sh` — прогоняет тесты, делает бэкап кода и базы, копирует изменённые файлы, применяет миграции и обновляет кэши. `.env`, `vendor`, `storage` на сервере не трогает.
- Правки прямо на сервере больше не делаем: только через репозиторий, иначе следующая выкладка их перезапишет.
- Бэкапы перед каждой выкладкой: `/root/backups/` (код, дамп базы, сайт).

## 5. Что сделано

**23.11 — репозиторий и данные заказчика:**
- Код API и админки перенесён в репозиторий проекта (`api/`, с историей). Сверен с сервером перед переносом: расхождений нет.
- В админке новый раздел «Настройки → Компания и контакты»: оператор ПДн, ИНН, ОГРН, адрес, часы, имя менеджера, телефон, WhatsApp, Telegram, e-mail. Данные проверяются при сохранении и сами попадают на сайт (подвал, «Контакты», политика ПДн, чат); пустые поля на сайте не показываются. Сайт пересобирается сам.
- Скрипт выкладки API `deploy/deploy-api.sh`.

**23.11 — аудит, безопасность, мобильная система:**
- Закрыта критическая дыра: публичная страница капчи раскрывала секрет и позволяла переписать `.env` сервера. Теперь она только для вошедших, токен проверяется, секрет заменён.
- Команда пересборки сайта задаётся только в `.env` на сервере (`SITE_REBUILD_COMMAND`), в админке её поменять нельзя.
- Токен бота не попадает в ошибки и логи. Недошедшие сообщения чата досылаются. Вебхук обрабатывает каждый апдейт один раз.
- Убраны выдуманные «выдачи» и непроверенные обещания («ответ за 15 минут»). Демо-каталог больше не может попасть на прод.
- Мобильная система (навык mobile-ui-system):
  - системный шрифт, шкала 11/13/15/17/22/30 px, сетка 4 px;
  - все цели нажатия от 44 px, без градиентного текста;
  - на телефоне быстрые действия и список «Топ-10».
- Ощущение приложения (навык app-feel-web):
  - отклик на нажатие, полоса перехода, вход страницы за 180 мс;
  - PWA: установка на экран, сервис-воркер, офлайн-страница. Решение описано в [adr/0001](adr/0001-pwa-service-worker.md).
- Проверено на проде: 9 страниц × ширины 320/375/390/430 px — нет переполнения и мелких целей. Сквозные сценарии: поиск → карточка → заявка, чат с ответом менеджера.

**23.11 — редизайн и реальные данные:**
- Главная перестроена по референсу:
  - «Почему выбирают» — заголовок закреплён слева, крупные цифры справа;
  - «Топ-10» — список по реальным данным рынка;
  - «Как мы работаем» — закреплённый экран с огромным заголовком и карточками, которые едут при прокрутке;
  - вопросы, чат с менеджером, финальный экран.
- Топ-10 собирается из фида: самые востребованные проходные модели, реальные фото, цена «от» по формуле (курс ЦБ × коэффициент + добавка).
- Ассистент и живой чат: частые вопросы отвечаются мгновенно, свой вопрос получает менеджер в Telegram, ответ реплаем появляется у клиента на сайте.
- Парсер работает по расписанию; при капче или ошибке приходит уведомление в Telegram.

## 6. Что осталось

1. **Подключить бота** — нужен токен от @BotFather и группа менеджеров (пункт 3). До этого заявки копятся только в админке и уйдут в Telegram сами после подключения.
2. **Наполнить витрину** — первые 20–30 карточек с ценой «от». Пока витрина пустая, на сайте демо-каталог.
3. **Заполнить «Компания и контакты»** в «Настройках»: юрлицо, ИНН, ОГРН, телефон, мессенджеры. До этого на сайте нет телефона и реквизитов.
4. **Репозиторий публичный.** В нём нет паролей и ключей, но код админки лучше держать закрытым: GitHub → Settings → Change visibility → Private.
5. **Яндекс.Метрика:** задать `NEXT_PUBLIC_YM_ID`, чтобы считалась цель «заявка».
6. Свой домен вместо `vanauto.neeklo.ru`, если нужен.
7. **Проверить формулу цены «от»** на 2–3 реальных сделках и поправить коэффициент и добавку в «Настройках».
8. **Фото из che168 с водяным знаком площадки** в углу. Для топовых карточек лучше загрузить свои фото или обработать их.
9. По желанию: фото в едином стиле (фон, логотип), видео для Shorts, сценарий бота с выбором бюджета.
